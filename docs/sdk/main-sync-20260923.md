## 仍未宣称完全等价的部分

- 主线的 Project Explainer、网页导航/折叠和 HTTP API 错误详情属于服务端/网页功能；独立 SDK 无对应界面或 Express API，不机械复制。
- **已于 2026-09-25 补齐：**主线的 `allowMainReconfiguration: true` 所需的 Main 工作流提案、权限和原子提交合同已接入 SDK。默认 `false`，显式启用后允许 Main 修改编排。SDK 后续扩展还允许在同一份 workflow.json 中修改 Agent prompt、模型/Harness、Skills/自动 Skills/MCP，已有和新增 Agent 均适用；服务端仍保留原来的宏观编排范围。
- 主线新版 Harness Runtime、工作区 checkpoint 和代理 provider-failure 生命周期遥测尚未整体移植到 SDK 的自包含运行时；现有 SDK 有自己的崩溃恢复和多轮测试，但不能据此宣称完全同构。
- 新增的四 Harness Web MCP 接线通过本地真实 MCP 客户端握手及模拟网关测试；尚需在连接 VPN 的环境中做四 Harness/真实模型端到端测试。macOS/Linux 也尚未验收。

不要把 SDK 分支合并回 `main` 或发布包，直到上述适用缺口已处理，并对最终打包产物完成真实网关和目标平台验收。
