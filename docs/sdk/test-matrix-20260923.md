可复现命令：

```sh

npm test -w sdk
npm run smoke:package -w sdk
```

`smoke:package` 会重新构建、打包，在临时目录安装 SDK 及依赖，再由独立 Node 进程执行模拟工作流。全新安装需要访问 npm registry。本次隔离环境首次执行时分别遇到 npm 缓存写权限和 registry 访问限制；改用工作区缓存并允许依赖安装后，smoke 通过。两次环境失败不能算作 SDK 功能通过，也没有修改 SDK 的运行逻辑来绕过验证。

1. macOS、Linux 上的四 Harness 端到端矩阵；Windows 上的两模型真实矩阵已经另行执行，但不能外推到其他系统。
