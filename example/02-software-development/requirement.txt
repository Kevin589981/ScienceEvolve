在 workspace 中实现 Node.js 命令行待办事项工具，使用标准库。

- node cli.mjs add "事项内容"：添加事项，返回稳定唯一 ID；空白内容报错。
- node cli.mjs list：按创建顺序显示 ID、内容和完成状态。
- node cli.mjs done <id>：标记完成，重复操作幂等；未知 ID 报错。
- node cli.mjs remove <id>：删除事项；未知 ID 报错。
- 数据跨进程持久化；TODO_DATA_FILE 指定文件，默认 workspace/todos.json。损坏文件保持原状并报错，无效命令或参数返回非零退出码。

沿用已有项目结构。Coding 实现，Testing 使用 Node.js 内置测试框架在临时目录独立验收并反馈修复，全部通过后结束。
